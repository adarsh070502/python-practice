# Python Practice

Projects from learning Python: games, automation, scraping, GUIs and interview-style problems.

- **Games:** `blackjack`, `higher_or_lower`, `Snakegame`, `pingpong`, `turtle-crossing`, `quiz-game-start`, `wordguessor`
- **Automation:** `SMTP` (email senders), `selenium_driver` (bots, LinkedIn jobs), `web_scraping`, `Mail Merge Project Start`
- **GUIs:** `TKINTER`, `Turtle_module`
- **Data:** `Pandas`, `Machine_Learning`
- **Interview prep:** `AAA_Interview_Preparation` (linked lists, matrices, searching, sorting), `ALGORITMS`
- **Other:** `calculator`, `password_generator`, `Inventory Management`, `SECRET AUCTION`, `chess_com_stockfish`

Credentials are read from environment variables (`EMAIL_PASSWORD`, `TWITTER_PASSWORD`, `SPOTIFY_CLIENT_ID`, ...).
